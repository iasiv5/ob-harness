**(CROSS) PRIMARY FOCUS — α exit-1 vs global exit-code contract — NO-BLOCKER**

The tension is **real** — the global contract (`bestpractice_06` table + global `Exit Codes` section in `ob --help`) literally says `1 = Failure — broken`, while smoke exit 1 is neither "broken" nor "usage error". But it is **documented + mitigated + sound under constraint**:

1. **The OVERRIDE banner** (`ob --help` smoke Options) explicitly declares it overrides the global line, and defines the α semantics precisely ("reports the BMC interface's ACTUAL state ... NOT 'smoke is broken'"). Positioned ABOVE the global section.
2. **The in-band α stderr line** printed at exit-1 time (`qemu_commands.sh:613`, correctly redirected `>&2` since `warn` defaults to stdout) — the most robust mitigation, present at the moment an agent acts, regardless of `--help` reference. An agent following `bestpractice_06` step 4 ("先读 ob 自己的报错" — read ob's own error output) sees it.
3. **ADR-0020** documents the trade-off and its acceptance explicitly ("verdict α 的代价（已接受）").

The realistic misuse scope is bounded: (a) for the **CI/gate primary use case**, smoke is invoked via `tools/smoke_diff.py` / `smoke_regression.sh` (per ADR-0020 consequences), which compare baseline-vs-current — α is handled by the diff engine, not raw `$?`, so no misuse here. (b) For **interactive/agent use**, the in-band α line + ✗ rows + RAW responses make diagnosis unambiguous. (c) The only misuse path is an agent that captures ONLY `$?` and discards all stdout/stderr — a degenerate agent `bestpractice_06` doesn't target (it explicitly instructs agents to read ob's output).

The design is also **constrained**: the contract's alphabet is `{0,1,2,3}`; exit 2 (user cancel), exit 3 (precondition missing — there IS an instance running), exit 0 (success — there ARE ✗ rows) are all wrong for "the BMC reported a ✗". Exit 1 is the only code that expresses "something is wrong". The α semantics are a reasonable reinterpretation of that code within smoke's scope. I would consider adding a back-reference footnote in the global `Exit Codes` section (an agent that grep-only jumps to that section would miss the smoke caveat), but this is a non-blocking improvement. "I would design it differently" is not within the blocker bar.
