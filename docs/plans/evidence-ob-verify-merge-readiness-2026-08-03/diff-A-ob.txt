+  <machine>               Whose running QEMU instance to probe (required positional)
+  Boundary: smoke is a READ-ONLY probe of ONE already-running instance. It does
+            NOT boot or tear down QEMU, installs NO EXIT trap, and honors NO port
+            overrides (--ssh-port/--redfish-port/--ipmi-port) nor --dry-run: the
+            three ports are read from the instance's PID file, so smoke reflects
+            the actual running instance, not a wish.
+  Prerequisite: a running instance started via 'ob start-qemu <machine>'. With no
+            instance (no PID file, or stale PID) smoke exits 3 and will NOT boot
+            one — run 'ob start-qemu <machine>' first.
+  Assertions (exactly 5, each probes the running BMC):
+            1. Redfish root reachable           (HTTP 200 + Redfish marker)
+            2. Redfish Managers reachable       (HTTP 200 + Manager resource marker)
+            3. Redfish SoftwareVersion reported (BMC reports firmware version)
+            4. IPMI over LAN works              (ipmitool mc info exit 0; needs an
+                                                 RMCP+/LAN responder in the image)
+            5. System ready signal              (SSH forwarded port TCP-connectable)
+  Exit codes (smoke-specific — they OVERRIDE the global "1 = broken" line below):
+            0   All 5 assertions passed.

+                see which interface and why (e.g. image lacks an RMCP+/LAN

+            3   No running QEMU instance (precondition) — 'ob start-qemu' first.
